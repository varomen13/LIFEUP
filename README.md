# LIFEUP

LIFEUP convierte hábitos y pendientes en misiones cortas. Completa retos para ganar experiencia, subir de nivel y mejorar tus atributos. La interfaz está pensada para la pantalla circular de un reloj Wear OS.

## Probar en el emulador Wear OS

1. Abre un emulador Wear OS desde Android Studio.
2. Instala las dependencias con `npm install`.
3. Inicia Expo con `npx expo start`.
4. Presiona `a` en la terminal para abrir LIFEUP en el emulador Android conectado.

También puedes iniciar Expo con `npx expo start --android` cuando el emulador ya esté abierto.
